# Samayran Portfolio

Premium 2D interactive portfolio for `samayran.in`.

## Stack
React + Vite + TypeScript + Tailwind CSS + Framer Motion + Lucide.

## Run
```bash
npm install
npm run dev
```

Production:
```bash
npm run build
npm run preview
```

## Replace portfolio content
Edit `src/data/content.ts`.

## Modes
- `#video` — Video Editor
- `#uiux` — UI/UX Designer

The mode is switched without a page reload and persists in the URL hash.
